# MasterOCR backend — heavy CPU engines
# Installed only when the image is built with INSTALL_HEAVY=true.
# Expect ~4 GB of extra image size and 5-15 s/page on CPU.
#
# This set is resolved as a whole against requirements.txt. Several engines are
# deliberately absent because their pins cannot coexist with the core set:
#
#   surya-ocr / marker-pdf  need pillow<11 and huggingface-hub>=1.5, but
#                           docling 2.14.0 needs huggingface_hub<1.
#   mineru                  needs pillow>=11, which surya-ocr forbids.
#   calamari-ocr            needs tensorflow<2.16 via ocrd-fork-tfaip, and no
#                           such wheel exists for Python 3.12.
#
# Those adapters stay registered and report as unavailable rather than breaking
# the build. Revisit when docling ships a huggingface_hub 1.x release.

torch==2.9.0
torchvision==0.24.0

# Docling is CPU-capable but pulls torch, so it lives here rather than in the
# default image. The registry marks it requires_heavy=True.
docling==2.14.0
